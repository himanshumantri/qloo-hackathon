# Qlooful Host: frontend

React + Vite single-page app. See the [main README](../README.md) for what the project does, how it uses the Qloo API, and how to run and deploy it.

```bash
npm install
cp .env.example .env   # VITE_API_URL defaults to http://localhost:4000
npm run dev            # http://localhost:5173
npm run lint
npm run build
```
